# Aprendiendo Kotlin 🚀

Este repositorio contiene mis avances y ejercicios prácticos mientras aprendo el lenguaje Kotlin. Estoy siguiendo un camino de aprendizaje combinado entre la formación académica y recursos complementarios.

## 📚 Fuentes de Estudio

Este proyecto se nutre de dos fuentes principales:

1. **Duoc UC**: Material oficial y guía académica de la institución.
2. **YouTube**: Refuerzo práctico a través del siguiente recurso:
   - [Curso de Kotlin - Video Tutorial](https://www.youtube.com/watch?v=i1PNVWd_dTY)

## 🛠️ Estructura del Proyecto

El repositorio está organizado por temas para facilitar la navegación:
- `condicionales/`: Ejercicios de control de flujo (`if`, `when`).
- `colecciones/`: Manejo de `List`, `Set` y `Map`.
- `duoc/`: Ejercicios específicos solicitados por la institución.
- `ejercicios/`: Prácticas generales y retos de código.
