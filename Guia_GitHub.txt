Guia GitHub

// Parte 1 - Subir proyecto a github
1) git init
2) git remote add origin (link repositorio)
3) git Branch -M main
4) git push -u origin main
-> (se agrega a GitHub el contenido del repositorio creado)

// Parte 2 - Actualizar proyecto
1) git add . 
2) git commit -m "describo avance"
3) git push
